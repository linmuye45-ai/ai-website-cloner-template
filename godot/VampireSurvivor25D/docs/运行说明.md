# 运行说明 — VampireSurvivor25D

## 环境要求
- **Godot 4.4**（官网 https://godotengine.org 下载，选 Standard 版）
- 无需额外插件，所有资源程序化占位

## 打开项目
1. 打开 Godot 启动器，点击 **导入**
2. 选择 `VampireSurvivor25D/project.godot`
3. 点击 **导入并编辑**

> 若提示缺少资源，确认已下载完整仓库，项目无外部依赖。

## 运行
- 直接按 **F5** 或点击右上角 ▶️ 运行
- 入口场景为 `scenes/main/Boot.tscn`（主菜单）
- 在编辑器中可直接运行 `scenes/main/Game.tscn` 快速进入战斗

## 打包

### Windows
1. 菜单 **项目 → 导出**
2. 若无模板，点击 **安装模板**（Godot 会自动下载）
3. 添加 **Windows Desktop** 预设，导出 `.exe`

### macOS
- 添加 **macOS** 预设，导出 `.app`（需在 Mac 上操作）

### Web (HTML5)
- 添加 **Web** 预设，导出后可用 `python -m http.server` 本地预览

### Linux
- 添加 **Linux/X11** 预设

## 常见问题

**Q: 启动黑屏？**
- 检查 `project.godot` 中 `run/main_scene` 是否为 `res://scenes/main/Boot.tscn`
- 查看 **输出** 面板是否有脚本错误

**Q: 敌人不动？**
- 确认 `GameManager` 自动加载已启用（项目设置 → 自动加载）
- 检查 `Player` 是否在场景中，`GameManager.player` 是否注册

**Q: 升级界面不弹出？**
- 升级由 `UpgradeSystem` 监听 `EventBus.player_level_up` 触发，需保证经验拾取正常
- 打开 **调试器 → 监视** 查看 `GameManager.game_time` 是否递增

**Q: 卡顿（300+敌人）？**
- 已开启对象池，默认 `max_enemies=350`，可在 `config/difficulty.json` 降低
- 关闭 **显示 → 高级 → 垂直同步** 提升帧率

## 存档位置
- Windows: `%APPDATA%\Godot\app_userdata\VampireSurvivor25D\savegame.json`
- macOS: `~/Library/Application Support/Godot/app_userdata/VampireSurvivor25D/savegame.json`
- Linux: `~/.local/share/godot/app_userdata/VampireSurvivor25D/savegame.json`
