# 操作说明 — VampireSurvivor25D

## 基础操作

| 操作 | 键位 |
|------|------|
| 移动 | **WASD** / **方向键** / 左摇杆 |
| 暂停 | **ESC** / **P** |
| 升级选择 | **鼠标点击** 卡牌 或 **1 / 2 / 3** |
| 结算重开 | **回车** / 点击按钮 |
| 返回菜单 | **ESC** 暂停 → 返回主菜单 |

> 游戏为 **自动攻击**，武器无需手动瞄准，自动索敌最近敌人。

## HUD 说明

- **左上 HP 条**：绿色→黄色→红色渐变，低血量闪烁
- **顶部经验条**：细长条，满后升级
- **右上 Lv**：当前等级
- **中上 计时**：存活时间 `MM:SS`，360秒（6分钟）胜利
- **右上 击杀**：累计击杀数
- **左下 阶段**：当前阶段名，如 `阶段 2: 潮汐`
- **底部 武器栏**：已装备武器及等级

## 武器详解

### 主动武器
1. **魔法飞弹** — 发射追踪飞弹，Lv3 双发，Lv5 三发，进化需 飞弹Lv5+疾风Lv3 → 歼灭飞弹（大爆炸）
2. **圣环** — 环绕旋转光环，持续伤害，Lv+半径，Lv+数量，进化需 圣环Lv5+生命Lv3 → 圣光新星（3秒全屏爆发）
3. **闪电链** — 在 3 个敌人间跳跃，递减伤害，进化需 闪电Lv5+急速Lv3 → 雷暴（周期落雷）
4. **火焰区域** — 在最近敌人处生成灼烧圈，持续 3 秒，每 0.3 秒伤害
5. **护盾反弹** — 5秒CD，1.2秒无敌并击退周围敌人

### 被动
- **疾风之靴** +12%移速
- **急速施法** -10%冷却（可叠至 -41%）
- **生命精华** +20最大生命
- **磁力光环** +25%拾取范围
- **毁灭之力** +15%伤害

> 升级时 3 选1 随机，优先出现已拥有未满级武器，新武器需先解锁（见存档）。

## 敌人与阶段

| 时间 | 阶段 | 敌人 | 特性 |
|------|------|------|------|
| 0:00 | 苏醒 | 史莱姆、蝙蝠 | 教学期 |
| 1:00 | 潮汐 | +骷髅 | 开始精英 |
| 2:00 | 围猎 | 蝙蝠、骷髅、石像鬼 | 密度上升 |
| 3:00 | 深渊 | +幽灵 | HP×2.0 |
| 4:00 | 领主降临 | 石像鬼、幽灵 | Boss 出现 |
| 5:00 | 永夜 | 全种类 | 最终考验，Boss 循环 |

- **精英**：金色描边，1.4倍大，3.5倍血，掉落大宝石
- **Boss**：吸血鬼领主，深红，2.2倍大，800血，全屏震动

## 拾取

- **经验宝石**：5档（tiny 5→epic 100），靠近自动磁吸
- **磁铁**（稀有）：全屏吸引宝石 4 秒（占位，未实装掉落，可通过 `activate_magnet` 测试）
- **血包**（稀有）：+20 HP

## 存档与解锁

- 每局结算自动存档 `user://savegame.json`
- **Lv5 解锁 闪电链**，Lv10 解锁 火焰区域，Lv15 解锁 护盾
- 最高等级/通关次数/总击杀/最长存活持久记录

## 技巧

1. 前期优先 **范围武器**（圣环/火焰）清群
2. 移动时 **绕圈** 聚怪，再用闪电链收益最大
3. 护盾可 **挡 Boss 冲撞**，CD 好就用
4. 拾取宝石有 **磁吸范围**，被动优先点磁力可减少跑图
