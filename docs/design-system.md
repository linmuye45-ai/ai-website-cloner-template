# NEXUS Commerce OS design system

## Direction
Enterprise commerce operations, not a generic AI landing page. Use task clarity and information density from Shopify Admin, financial precision from Ramp, workflow hierarchy from Linear and typography/spacing discipline from Stripe. Extract patterns; do not copy branding.

## Tokens
- Canvas #F5F6F8; surfaces #FFFFFF; ink #111827.
- Primary #15243A; action blue #315CEB; success #16835D; warning #B7791F; danger #C2413B.
- Borders #E5E7EB; secondary text #667085.
- Modern sans for operational data; editorial serif only on retained VESTI fashion surface.
- 8px spacing scale; restrained shadows; 8–12px radius.

## Interaction rules
- Show real loading, empty, error and success states.
- Never show fabricated metrics as live data.
- External publishing always requires human approval.
- Visible keyboard focus, semantic labels, WCAG AA contrast and reduced-motion support.
- Screenshot QA at 1440/768/390 widths; two screenshot-based critique iterations before release.

## Release rubric
Identity 20, composition 20, typography 15, colour 10, spacing 15, motion 10, responsive/accessibility 10. Release threshold 90/100.
