# 第三轮 · 乔布斯 + 黄峥 + 贝索斯式「个人超级公司」创业系统任务书执行结果

> 执行角色:你的联合创始人(不是顾问)
> 约束:没有资本、没有团队;拥有全球最先进模型、自动化工具与开源资源;路径必须是「一人公司 → 十人公司 → 百人公司」
> 一句话结论:**All in「Landed(到岸)」——站在买方这一边的 AI 贸易公司。** 过去一家利丰需要两万人;2026 年,一个人加一群代理可以做同一件事,并且在第一个月就有现金流。它满足三位导师的全部标准,是十个候选中唯一一个「零资本、第一个月收钱、天花板在万亿美元级别的贸易中介利润池」的方案。

## 0. 先校准「一人公司」在 2026 年到底成立到什么程度

- Medvi(GLP-1 远程医疗):2 名员工,$2 万启动,首年收入 $4.01 亿,2026 年预计 $18 亿——完全靠外包履约(复方药房)+ AI 做营销/客服/运营。
- Midjourney:约 107 人,2025 年收入 $5 亿;Cursor 人均收入约 $330 万;Pieter Levels 一个人运营 $300 万+ ARR 的产品组合。
- Altman 在 2026 年给「一人独角兽」的概率是 70–80%,点名三类:自营交易、开发者工具、**围绕自动化客服建立的业务**。

从这些样本抽象出「一人公司」成立的三个条件,它们就是本轮的筛选器:

1. **履约可外包**(药房、工厂、物流、检验、云);
2. **需求已存在且正在因外部冲击而重排**(GLP-1 之于 Medvi;关税与小额免税取消之于进口商);
3. **AI 替代的是「桌面知识劳动」**(找、比、谈、算、填、追),而不是替代物理劳动或创造新需求。

Medvi 的教训同样重要:它是一个**品牌**,不是一个**平台**,护城河薄。一人公司要走到千亿,必须在现金流成立后迅速把「我做的事」变成「别人通过我做事」。

## 1. 十个领域全面扫描

每个领域回答任务书要求的九个问题(市场规模为 2026 年量级估计)。

### 1.1 AI 游戏

| 问题 | 回答 |
| --- | --- |
| 市场规模 | 全球游戏约 $1,900 亿/年 |
| 当前玩家 | 大厂(任天堂/索尼/微软/腾讯)、Roblox、Genie 3 类世界模型(Google)、数千 AI 小团队 |
| 为什么没解决 | 大厂受制于 IP 与工会/成本结构;世界模型公司做模型不做「玩法」;小团队做的多是「AI 生成素材的旧游戏」 |

| 第一个 Demo | 一个小镇、20 个有记忆的 NPC、玩家离开一周回来时镇子变了 |

| 增长方式 | 玩家生成的故事在短视频平台传播 |

| 问题 | 回答 |
| --- | --- |
| 市场规模 | 全球贸易约 $33 万亿(2024 创纪录);中介(贸易公司、采购代理、货代、报关)利润池以万亿美元计;贸易融资缺口约 $2.5 万亿 |

| 一人公司判断 | **三个条件全部满足:履约全部可外包、需求正因关税冲击而重排、AI 替代的是桌面知识劳动;且第一个月有现金流。** |

**评分说明(诚实部分):**
- 三个幸存者里,有两个(Ember、给父母的 AI)是同一个洞察——「App 时代抛下的人是语音 AI 的最佳用户,而巨头被锁在门外」——与第一轮收敛。这种跨任务书的收敛,正是你说的「人工筛选共同出现的机会」应该捕捉的信号。
- Ember 在第一轮的「产品革命」标准下是第一名,在本轮的「零资本个人启动」标准下只以 90 分压线:它需要 12–18 个月建立家长信任才能规模化收费,这是**风险投资路径**;Landed 第一个月就有现金,是**自举路径**。两者都对,取决于你有没有 18 个月的生活费和对融资的态度。
- 方案 4 是最容易第一天收钱的,但它是「生意」而不是「公司」:切换成本接近零,定价权会被几百个同类产品抹平。

## 3. 最终项目:Landed(到岸)

### 用三位导师的标准检验

| 标准 | Landed 如何满足 |
| --- | --- |
| **乔布斯:极度简单、无需学习、第一次体验震撼** | 输入是一句话或一张图(「我要做这款保温杯,印我的 logo,5,000 个」);输出是一张「到岸表」和一个「下单」按钮。用户第一次看到自己的**真实到岸成本**,大多数人会发现过去多付了 20–40%。 |
| **贝索斯:趋势明确、十年后仍存在** | 全球贸易不会消失;它正在变得**更碎片**(多国货源、关税多变、合规加码),碎片化让「有智慧的中介」更值钱而不是更便宜。十年后一定还有人要把东西从工厂运到仓库,但不会再有人愿意为此养一万名采购员。 |
| **黄峥:隐藏需求、结构性成本优势、效率差** | 隐藏需求:中小买家要的不是「更多供应商列表」(阿里已给了 1,000 万人),而是**有人为结果负责**。结构性成本优势:传统贸易公司抽 10–30% 养人,Landed 用代理做全部桌面劳动,抽 6–10% 仍有高毛利;双语创始人同时拥有中国工厂侧的信任与美国买家侧的信任——这是阿里和 Cavela 都不同时具备的。效率差:询价从两周到 48 小时;报关归类从「找报关行等三天」到即时。 |

### 产品名称

**Landed(到岸)。** 英文是一个状态(「到了」),也是行业术语「到岸成本」;中文「到岸」同义,且天然带「可靠」的意味。

### 品牌理念

> **站在买方这一边的贸易公司。**
> 三条承诺:(1)**透明**——工厂价、我们的加价、每一项税费分开列示,永远;(2)**负责**——货到仓、验货合格、合规清关,否则我们赔;(3)**不站队**——不绑定任何平台、国家或工厂,只为买方的到岸成本与风险负责。

### 一句话广告

> **「说一句你想做什么产品。到岸、验过、合规、保了险。」**
> *(Say what you want made. It lands — inspected, compliant, insured.)*

### 用户第一天体验

1. **上午 9:00** — 一位凤凰城的 Shopify 宠物用品卖家把一个竞品链接和一句话贴进 Landed:「类似这款,升级成不锈钢碗,印我们 logo,首单 3,000 个,到我们在亚利桑那的仓。」
2. **9:03** — Landed 回问三个问题(目标到岸单价?可接受交期?是否需要 FDA 食品接触材料合规?),并说明:「48 小时内给你到岸表,样品可一键下单,货款托管。」
3. **接下来 48 小时(用户看不见的部分)** — 规格代理把一句话变成技术包;寻源代理群在 1688、Alibaba、Made-in-China、IndiaMART 与线下微信工厂网络里找出 60 家候选,剔除贸易商,用中文/英文/印地语在微信/WhatsApp/邮件上完成首轮询价与两轮议价;合规代理做 HTS 归类(持牌报关行复核)、算出 2026 年当期的完整关税栈与 FDA 食品接触合规路径;到岸代理拉取货代报价、保险、最后一公里;核验代理为入围工厂预约第三方验厂记录并标记 UFLPA 风险。
4. **次日 9:00** — 用户收到**到岸表**:5 家工厂(3 家中国、1 家越南、1 家印度),每家一行——单价、MOQ、交期、关税栈、到仓每件成本、风险标记、过往 Landed 订单的准时率与不良率(Landed 的供应商结果评分)。底部一行字:「按你现在的供应商报价推算,你的到岸成本比第 2 家高 31%。」
5. **9:10** — 用户点「下 3 家样品」,$180 进入托管;样品 10 天后到达,附第三方验货报告。
6. **第 14 天** — 用户下首单 3,000 个,30% 定金托管;Landed 以委托人身份向工厂下单,验货合格后放款,货到仓后结清。

**震撼点:** 不是 AI 多聪明,而是**一个人第一次看见自己生意的全部真相**(真实成本、真实风险、真实替代方案),并且有人为结果负责。

### 核心技术架构

```
┌──────────────────────────────────────────────────────────────────┐
│ 1. 需求摄入层    一句话/图片/链接 → 结构化技术包(材质、工艺、尺寸、    │
│                  认证需求、目标成本、交期);缺失信息回问                │
├──────────────────────────────────────────────────────────────────┤
│ 2. 寻源代理群    多平台抓取 + 多语言谈判代理(微信/WhatsApp/邮件);       │
│                  工厂 vs 贸易商识别;报价归一;两到三轮议价脚本            │
├──────────────────────────────────────────────────────────────────┤
│ 3. 合规引擎      HTS 归类(LLM 初判 + 持牌报关行复核与签字);          │
│                  当期关税栈(基础税率 + 各类附加税 + 原产地规则);       │
│                  产品安全(FDA/CPSC/UL/FCC)、UFLPA、标签要求            │
├──────────────────────────────────────────────────────────────────┤
│ 4. 到岸成本模型  货代 API 报价 + 保险 + 港杂 + 最后一公里 → 到仓每件成本 │
├──────────────────────────────────────────────────────────────────┤
│ 5. 核验与托管    第三方验货(QIMA/SGS/V-Trust 类)预约与报告解析;      │
│                  托管付款与放款条件(验货通过 / 签收);争议流程            │
├──────────────────────────────────────────────────────────────────┤
│ 6. 供应商结果评分 每笔订单回写:准时率、不良率、响应速度、议价弹性        │
│                  (= 第二轮 OutcomeRank 在工厂世界的实例)               │
├──────────────────────────────────────────────────────────────────┤
│ 7. 创始人控制台  「例外收件箱」:只有代理无法决定的事才到人面前           │
│                  (异常报价、验货不合格、工厂失联、合规灰区)              │
├──────────────────────────────────────────────────────────────────┤
│ 8. 资金层(第二年)  托管 → 买方账期(Net-60)→ 工厂早付 → 贸易融资       │
└──────────────────────────────────────────────────────────────────┘
```

**设计原则:** 代理做 95% 的桌面劳动;人只处理例外;所有物理动作(验货、运输、报关签字)外包给持牌/专业第三方并 API 化;每一笔订单都为供应商评分与合规知识库增加一条无法被竞争者抄走的数据。

### 商业模式(分年演进)

| 年 | 模式 | 说明 |
| --- | --- | --- |
| 第 1 年 | **委托人加价** 6–10% + 样品费 | 以 Landed 名义向工厂下单、向买家交货;定金托管,无库存风险。传统贸易公司/采购代理抽 10–30%。$100 万 GMV ≈ $8 万毛利,一个人即可盈亏平衡。 |
| 第 2 年 | + **Landed Pro 订阅** | 面向复购进口商:SKU 成本监控、关税变动预警、多国货源对冲、年度重新寻源。$299–999/月。 |
| 第 3 年 | + **嵌入式贸易融资** | 买方 Net-60 账期、工厂早付折扣——贸易中介最厚的利润池(全球贸易融资缺口约 $2.5 万亿);以 Landed 自己的订单履约数据定价风险;用债权融资而非股权融资来放贷。 |
| 第 4–5 年 | + **平台化** | 工厂为 Landed 的询价竞标(可提供保证金挂牌);「Landed Verified Factory」认证;供应商结果评分向第三方(保险、银行、平台)授权;Landed 从「做贸易的公司」变成「贸易通过它发生的层」。 |

### 增长飞轮

```
每一笔订单 → 供应商数据与结果评分更厚 → 下一张到岸表更快、更准、更便宜
     ↑                                                      ↓
工厂优先响应 Landed 的询价(因为订单量)← 更多买家 ← 买家在卖家社群里分享「真实到岸成本」
     ↑                                                      ↓
更好的价格与交期 ←──────── 复购率上升、客单上升 ←─── Pro 订阅与账期把客户锁进年度关系
```

三个加速器:
1. **透明内容**:每月发布「真实到岸成本报告」(按品类、按原产国、含关税栈)——卖家社群会自发传播,因为没有人给过他们这个;
2. **合规即获客**:小额免税取消后每一个小进口商都要 EIN、报关行、HTS 归类——Landed 免费提供「关税计算器 + HTS 归类初判」作为前端漏斗;
3. **工厂侧飞轮**:当一家工厂通过 Landed 拿到稳定订单,它会把最好的报价和产能留给 Landed——这是阿里做不到的(阿里向工厂收费,Landed 给工厂订单)。

| 对手 | 它的优势 | 它的结构性弱点 | Landed 的位置 |

| **传统贸易公司 / 采购代理** | 关系、经验 | 成本结构(人)、不透明、不可扩展 | 价格一半、速度十倍、全程透明 |
| **货代 / 报关行(含 Flexport)** | 物流与清关执行 | 不做寻源与谈判,不为采购结果负责 | 合作方与供应商,而非对手;Landed 把订单给它们 |

| **巨头通用代理(OpenAI/Google)** | 入口 | 不会承担实物贸易的责任与合规签字 | 让它们调用 Landed(第二轮逻辑) |

**真正的护城河按时间叠加:** 第 1 年是速度与透明;第 2 年是供应商结果数据;第 3 年是融资与风控数据;第 5 年是「贸易通过 Landed 发生」的双边网络。

**原则:** 只在「代理做不了、合同方不愿负责」的位置上招人。每一个新员工都应该让你的「例外收件箱」变短。

### 融资路线

| 阶段 | 资金 | 来源 | 为什么 |
| --- | --- | --- | --- |
| 第 0–9 月 | **$0 股权融资** | 客户定金(托管)+ 加价毛利 | 委托人模式对确认订单采购,无库存;第一个月即有现金流;不要在没有数据时按故事估值 |
| 第 9–12 月 | Pre-seed $1–2M | 天使 / 早期基金 | 招前两名员工、建代理系统;此时你有 6 个月的 GMV、毛利、复购与不良率数据 |

**纪律:** 融资永远跟在数据后面,不跟在叙事后面;金融用债,平台用股。

### 国际扩张路线

**供给侧(货源国):** 中国(2027)→ 越南、印度(2028)→ 墨西哥、土耳其、印尼(2029)→ 全球(2030+)。2026 年买方的真实需求已经是「多国对冲」,Landed 从第一天就是多国报价,但工厂关系按国逐个深耕。

**需求侧(买家国):** 美国中小进口商(2027)→ 英国/欧盟(2028;脱欧后进口复杂度与 EU 的产品安全新规是同样的「合规即获客」逻辑)→ 拉美、中东(2029)→ 亚洲内部贸易与近岸(墨西哥→美国)反向流(2030)。

**原则:** 每进入一个买家市场,先复制「合规即获客」的免费前端;每进入一个货源国,先招一位有十年工厂关系的人,再放代理进去。

## 4. 2035 年回顾:为什么这家公司在 2026 年诞生,并改变了世界

> **《到岸十年》(写于 2035 年)**
>
> 回头看,Landed 的诞生时间精确到季度并不是巧合。
>
> 2026 年秋天,三件事同时发生了。第一,美国彻底取消了小额免税:每一个曾经靠「工厂直邮小包」活着的小卖家,一夜之间需要 EIN、报关行、HTS 归类和一份他们从未见过的「关税栈」——几十万个微型企业同时需要一个贸易专家,而世界上没有那么多贸易专家。第二,多语言代理第一次能在微信和 WhatsApp 上和一家义乌工厂用中文讨价还价,然后用英文向一个凤凰城的卖家解释结果,成本接近零。第三,世界上最大的采购平台已经有一千万人在用它的 AI 找工厂,但它的商业模式决定了它只能「帮你找」,不能「替你负责」——它向工厂收钱。
>
> 一个人看见了这三件事的交点。他没有做一个「更好的采购搜索」,他做了一家**贸易公司**——只是这家贸易公司第一年只有一个员工和几十个代理。他以自己的名义向工厂下单,把定金放进托管,请第三方验货,签合规文件,货到仓才收尾款。他做的事情和 1906 年的利丰一模一样,只是不需要两万人。
>
> 第一年,Landed 做了 $300 万的生意,毛利 8%,他靠这个活了下来,并且积累了一样所有竞争者都没有的东西:**几百家工厂在真实订单下的准时率和不良率。** 第二年,他招了一个在广州做了十五年工厂关系的人和一位持牌报关师,开始给复购客户账期。第三年,Landed 的「真实到岸成本报告」成了独立卖家圈子里的月度事件,工厂开始把最好的产能留给 Landed 的询价。第四年,它开始放贷——用自己的履约数据定价风险,坏账率是银行贸易融资的三分之一。第五年,越南、印度、墨西哥的工厂为 Landed 的询价竞标,并愿意缴保证金。
>
> 到 2032 年,人们不再说「我在 Landed 采购」,而是说「这批货走 Landed」——就像以前说「走 FedEx」。全球中小企业进口中,有可观比例的订单在到达工厂之前,先经过了 Landed 的到岸表、合规引擎和供应商评分;而银行、保险公司和平台开始购买这份评分,因为它是世界上唯一一份「哪些工厂真的能把货做好」的记录。
>
> Landed 改变世界的方式很安静:它没有发明新的商品、新的工厂或新的航线。它只是让「为结果负责」这件以前只有大公司买得起的东西,变成了每一个小生意的默认配置。贸易公司的历史是人的历史——十年前,一个人和一群代理证明了,它也可以是软件的历史。
>
> 而这家公司之所以诞生于 2026 年而不是 2024 年或 2028 年:2024 年代理还不能可靠地谈判,2028 年窗口已经被人占了。**它诞生于需求被外力重排、工具恰好成熟、而在位者被自己的商业模式锁住的那一个季度。** 这是所有伟大公司的出生证明。

## 附录 A:为什么不是 Ember(如果你有 18 个月的生活费,请重读这一段)

Ember 的天花板不低于 Landed,壁垒更高(十年的学习记录 + 监管)。它输给 Landed 只在两个维度:**个人启动**(需要 12–18 个月建立家长信任、且第一天不能像 Landed 那样对一笔交易收 8%)和**全球扩张**(课程与语言的本地化)。如果你能承受 18 个月没有收入、并愿意走风险投资路径,Ember 是更大的公司。如果你必须自举,Landed 是唯一一个第一个月就付得起房租的千亿级方案。最务实的组合:**先用 Landed 建立现金流与「代理 + 外包履约」的组织能力,18 个月后以同一套能力启动 Ember 或「给父母的 AI」。**
