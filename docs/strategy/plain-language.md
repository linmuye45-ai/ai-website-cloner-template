# 白话版 · 写给文科生的战略解释

> 这份文件不出现一个不解释的行话。读完你应该能向任何人讲清楚:我们在做什么生意、为什么能成、为什么别人抢不走、以及说实话有多大胜算。
> 行话对照表在文末(第七节),忘了随时查。想看带数据和出处的严谨版,读 round-1 到 round-6。

---

## 一、先讲个故事

Sarah 在亚利桑那开网店,卖宠物碗。她想进 3,000 个不锈钢碗,印上自己的牌子。

放以前,她得这样:上阿里巴巴搜工厂,发 50 封信,收到 30 个报价——有的虚高,有的是中间商冒充工厂。她挑一个看着顺眼的,把钱打过去,等 40 天。货到了:logo 印歪了,材质不对,海关还扣了货——因为她不知道这东西要交多少种税、要什么证明。钱亏了,三个月也搭进去了。

**「到岸」做的事:她只需要说一句话**——「3,000 个不锈钢宠物碗,印我 logo,发到我亚利桑那的仓库」——然后等 48 小时。

她收到一张单子(我们叫它「到岸表」,你可以理解成**装修队的全包比价单**):

- 5 家工厂(3 家中国、1 家越南、1 家印度),都是真人核实过的;
- 每家的报价、多少件起订、多久交货;
- **重点:从工厂到她仓库,每个碗最终花多少钱**——把各种税、运费、保险全算进去了;
- 哪家有合规证明(美国对装食物的碗有规定),哪家有黑历史;
- 底部一行字:「你现在这家供应商,到手成本比最划算那家贵 31%。」

她在单子上挑一家,点确认。钱先放在中间托管(像支付宝),我们盯着工厂生产、请人验货、办清关、运到她仓库。**货验合格,钱才给工厂。出了问题,我们赔。**

我们收 6% 的服务费,明码标价,写在单子上。

这就是这门生意的第一步。记住这个故事,后面全是它的展开。

## 二、为什么是现在?(以前为什么做不了?)

1. **天时:美国把「800 美元以下免税」的口子堵死了。** 以前从中国发个小包裹,800 美元以内不用交税——无数小卖家靠这个活着。2025 年起美国把这个优惠全面取消,一夜之间几十万小卖家都要自己报关、算税、找报关行。这些是又专业又繁琐的活,以前只有大公司才养得起专家。**市场突然多出几十万个需要帮忙的人。** 而且税还一年变好几次,更没人看得懂。

2. **地利:AI 第一次能干「跑腿 + 砍价」的活。** 找工厂、发消息、比价、盯生产,以前要养一整个采购团队,现在 AI 能干大半。它还会中文又会英文:能用微信跟义乌的工厂砍价,再用英文跟凤凰城的卖家解释。

3. **人和:买家这边没人帮。** 阿里巴巴赚的是工厂的钱(工厂在阿里身上花钱做推广),所以它只能帮你「找到」工厂,不敢替你「负责」。出了事,赔付是象征性的。**谁站在花钱的买家一边,谁的位置就是空的。**

## 三、这生意怎么赚钱?(四步,一步比一步肥)

**第一步:中介费(现在)。** 每单收 6%。传统贸易公司收 10–30%,因为他们养一大堆人;我们的「员工」大部分是 AI,所以收 6% 还有得赚。

**第二步:会员费(第 6 个月起)。** 老客户每月交几百美元,我们盯着他的成本:哪个料涨价了、税又变了、什么时候该换工厂。相当于给小店铺雇了个「常驻采购顾问」。

**第三步:放贷(两三年后,最肥的一步)。** 做买卖最缺钱:买家想先拿货后付款(像花呗),工厂想马上拿到钱、不想等两个月(那就给个折扣提前付)。**银行不肯借钱给这些小公司——不是怕他们亏钱,是不了解他们,又没东西抵押。** 而我们天天盯着他们的货:货到没到、质量好不好、钱还得及不及时,一清二楚。所以别人不敢借的我们敢借,还知道该收多少利息。这一步是利润的大头,也是「千亿」的关键。
  - 榜样:阿根廷的 MercadoLibre(拉美的「淘宝 + 支付宝 + 银行」,市值约 7,000 亿人民币)。**光卖货做不大,放贷才大。**

**第四步:立标准(更远)。** 让全行业都用我们的「到岸表」格式比价,像大家开发票都用同一个样子。到那时,这门生意的「水电煤」都是我们的。

## 四、为什么别人抢不走?(护城河,白话)

先讲两个别人踩过的坑:

- **坑一:Flexport(美国一家有名的「物流科技公司」)。** 它想用互联网改造海运,干了十年,最近才承认走错了:运费是「赚差价」的苦生意,利薄得像纸,烧投资人的钱转不回来,估值从 80 亿美元跌到 25 亿,「盈利」还是靠卖副业资产装出来的。**教训:别在赚差价的苦生意里建帝国。** 我们不碰运输差价。
- **坑二:IndiaMART(印度的阿里巴巴)。** 它做到了全印度第一,但客户「找完工厂就跑」——后面的运输、付款都不在它那儿发生,人留不住。**教训:光做「牵线」锁不住人,得管到「成交」。**

所以我们的六条「防抢」工程:

1. **攒成绩单。** 每一单都记下来:货准时吗?质量好吗?钱还得快吗?这些记录越攒越值钱——到放贷那一步,它就是我们敢借钱的底气。这是银行花十年也买不到的东西。
2. **让客户离不开。** 出事我们赔、验货合格才付款、想赊账找我们。想跳过我们直接找工厂?行,出了事自负。**6% 买的是「有人兜底」,不是「一个联系方式」。**
3. **让大家用我们的单子。** 比价单格式公开,谁都能用——用的人越多,「到岸表」越像行规;而只有我们的单子上有真数据。
4. **先打透一个地方。** 不摊大饼。先把「美国卖宠物碗的圈子」做到人人认识我们,再做下一个品类、下一条进货路线。生意的规矩是:**在一个小圈子里当第一,比在十个圈子里当第五值钱一百倍。**
5. **有钱才能放账。** 我们能给买家赊账、给工厂提前付钱,靠的是银行给我们的额度(像信用卡额度,但是公司级的)。这个额度本身就是墙:新对手没有额度,就给不了这些好处。
6. **攒案例。** 海关的每个问题、每个税号怎么归类,都记下来,下次又快又准。纯功夫活,靠时间,偷不走。

**大公司为什么不来碾死我们?**

- **阿里:** 它赚工厂的钱。真帮买家砍价、替买家出头,等于革自己的命。大公司都怕这个——管这叫「创新者的窘境」:柯达做不了数码、诺基亚做不了智能机,一个道理。
- **亚马逊:** 它自己就是最大的卖家,不可能中立地替你找别家的货。
- **做聊天机器人的大 AI 公司:** 聊天机器人能帮你比价,但「货到、合格、赔钱」是要真金白银兜底的——这是开银行 + 开保险公司的活,不是写代码的活。

## 五、目标,和说实话

- **三年后:** 目标是公司「值」100 亿美元(约 700 亿人民币)。注意:这是别人估的价,不是银行里的钱。创始人想把估价换成现金,只能一点一点卖自己的老股份,三年下来大概能拿到 1.5–5 亿美元。真正想要「十亿现金」,得等公司做到 300 亿估值,或者被大公司花大价钱买走。
- **十年后:** 目标 1,000 亿美元(约 7,000 亿人民币)市值,像 MercadoLibre 那样。
- **说实话:概率 1–2%。** 这类生意做成「千亿」的凤毛麟角。另外两个点子各自不超过 2%。三个都试,加起来 3–5%。**没人能向你保证任何事——这套文件的价值是把每个假设写下来、逐条检验,而不是讲故事骗自己。**

## 六、另外两个点子(一句话版)

- **Ember(星火):** 给孩子的 AI 私教——从 3 岁陪到 18 岁,主要靠「说」和纸笔,不抢孩子的屏幕;爸妈每周收到一封「老师写的信」。大公司不敢碰小孩的生意(法律和家长投诉),所以我们有机会。难的是让孩子自己想回来(这行的通病是孩子玩两个月就腻)。
- **Praxis(行索):** 给 AI 助手用的「大众点评」——哪家公司能把什么事真正办成,打分排名。现在先不独立做,改成给「到岸」当内部数据工具。

| 二级出售 / 变现 | 创始人卖一点自己的老股份换现金 |
| 护城河 | 别人抢不走你生意的原因 |
| 网络效应 | 用的人越多越好用(淘宝:卖家多 → 买家多 → 卖家更多) |
| 坏账 | 借出去收不回来的钱 |
| 账期 / Net-60 | 先拿货,60 天后再付钱(赊账) |
| 信贷账面 | 放出去还没收回的借款总额 |

## 八、如果只记三句话

1. **生意是什么:** 一句话下单,48 小时给一张「全包比价单」,盯到货到合格,收 6%;以后再放贷。
2. **为什么是现在:** 站在买家一边的位置是空的;AI 让 6% 也能赚钱;美国税改让几十万小卖家突然需要帮忙。
3. **怎么不被抢走:** 攒成绩单(数据)→ 客户离不开(赔付 + 赊账)→ 行业用我的格式(标准)→ 先打透一个圈子(密度)→ 有钱放账(资本)→ 攒案例(功夫)。
