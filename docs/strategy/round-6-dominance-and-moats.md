# 第六轮 · 龙头老大与极强护城河 —— 护城河的工程学

> **命题:** 得确保成为龙头老大,有极强的护城河。
> **日期:** 2026-10 · **方法:** 与前五轮一致(2026 年 10 月事实校准 + 投委会三问;来源见文末附录)。
> **这一轮的产出:** 六条护城河工程(每条有「第一天决策」与健康度指标)、一张防御地图(每个对手的进攻路径与最坏情况对策)、一台龙头仪表盘(怎么知道自己在赢、什么时候承认不是龙头)。

---

## 0. 命题与三条铁律

**铁律 1:护城河不是宣称,是工程。**
每一条护城河都必须能指认为「花了时间/金钱建成的具体资产」,并且有可测量的健康度。「我们的护城河是 AI」不是护城河——2026 年的 AI 是所有人都能调用的商品。「我们的护城河是 34 万单履约数据 + 一张 $1B 的信贷账面」才是护城河。

**铁律 2:AI 降低了「建」的成本,没有降低「信任」的成本。**
(2026 年最准确的一句行业判断:"AI has collapsed build cost; it has not collapsed sell cost." [R6-5])
Cavela 用 13 个人做到了 20 万家供应商的寻源网络 [R6-3];任何人都能复制 Landed 的软件。但没有人能用提示词生成:200 个信任你的工厂的优先响应、一家银行给你的信贷额度、一份被行业当成标准的到岸表、以及十年的履约记录。**网络、账面、数据、信任,是唯四不能被生成的东西。**

**铁律 3:龙头 ≠ 赢者通吃。这个市场的形状决定了龙头的形态是「默认选项」。**

### 0.1 龙头的定义:这个市场的形状

| 事实 | 数字 | 出处 |
| --- | --- | --- |
| SME 占全球跨境贸易量 | 43% | WTO [R6-4] |
| SME 跨境 B2B 支付市场 | ≈ $20 万亿/年 | WTO/OECD 估算 [R6-6] |
| 全球贸易金融缺口 | $2.5 万亿(≈ 全球贸易 10%,连续三年持平) | ADB 2025 调查 [R6-4] |
| SME 贸易融资拒贷率 | 41%(跨国公司 20%;SME 被拒概率是大公司的 7 倍) | ADB / WTO [R6-4] |
| 贸易融资的真实坏账率 | **<0.2%**(ICC Trade Register) | [R6-7] |

关键推论:**拒贷是信息问题,不是风险问题。** 银行拒掉 41% 的 SME 申请,不是因为这些生意会亏钱(真实坏账 <0.2%),而是因为银行看不到履约记录、没有抵押物、合规成本高。而 Landed 的每一单都在生产银行看不到的东西:验货结果、清关放行、交期与不良率、付款行为。**第六轮的核心结论:护城河的原料是履约数据,护城河的成品是信贷账面,两者构成一个别人进不去的飞轮。**

市场结构:多国、多品类、多合规 = 结构性碎片化,不会赢者通吃。龙头形态 = 「默认选项」:像 SAP 之于 ERP、Adobe 之于创意、IndiaMART 之于印度 B2B(60% 份额、"quiet monopoly" [R6-2])。份额数学:$100B 时 GMV $150–250B ≈ 全球 SMB 跨境贸易的 2–4%——但在「单走廊 × 单品类」的密度市场里,可以做到 30–50% 的第一联想。**龙头从密度里长出来,不从广度里长出来。**

### 0.2 现在的格局:谁占了哪一层,哪层是空的

| 层 | 谁在做 | 状态(2026-10) |
| --- | --- | --- |
| 找厂 / 发现层 | 阿里 Accio(1,000 万月活)、IndiaMART、Cavela(20 万供应商)、Thomasnet | **已商品化。** Cavela 证明 13 个人就能做「找」;省 35% 的报价都拿得到 |
| 执行 / 物流层 | Flexport($2.1–2.4B 收入)、货代们 | **毛利被压扁的苦生意。** 运价差 10% 毛利、8–12% 净利 [R6-1] |
| 合规层 | 报关行、Flexport 海关业务 | **价值在上涨。** Flexport 海关/合规毛利 +99% YoY(2025)[R6-1] |
| 金融层 | 银行(拒贷 41%)、Flexport×BlackRock($250M)、IndiaMART Finance(2026-06 新设)[R6-2] | **所有人冲向这里,但都缺履约数据** |
| **责任层(为结果负责)** | **没有人** | **空的。** Trade Assurance 事后、平台内;没有任何人为「到仓合格且总成本最低」负责 |

**结论:Landed 站在责任层(入口)+ 金融层(利润池)。发现层只用来引流,执行层只用来交付。绝不做货代的运价差生意——那是 Flexport 的坟场。**

## 1. 先诚实:每一幕的护城河审计(含 Flexport 尸检)

### 1.1 Flexport 尸检:数字化 ≠ 护城河

Flexport 是「用技术改造贸易」最响亮的案例,2026 年的它是一份活教材 [R6-1]:

- 「盈利」是卖资产卖出来的:2025 年技术性盈利靠一次性出售 Convoy($16M 买入 → $250M 卖出),有机经营仍亏损;原定 2024 年底的盈利目标一再跳票。
- 估值从 $8B(2022 零利率顶点)被二级市场标记到 ~$2.5B(−69%)。四轮裁员 1,600+ 人。
- 根因是经济结构而不是执行:货运代理运价差 ≈ 10% 毛利、全业务线 8–12% 净利;风投股权要求 30%+ IRR,传统同行用 4–8% 成本的债务。**在毛利被压扁的层里,股权帝国在数学上不成立。**
- 2026 年 6 月,Petersen 公开转向「成本领先」,承认此前"was lying to myself";目标净收入 $450M → $600M,Agent 化 100 个核心工作流(5 个已上线)。

**对 Landed 的三条戒律:**
1. **不做货代、不碰运价差。** 运价差是估值折价机。
2. **不垫库存、不建仓。** 仓储性融资只在幕三以「融资」形式出现,不以「地产」形式出现。
3. **价值只从两处收:责任(6–10% 服务费)+ 金融(利差与服务费)。** 前者是入口,后者是利润池。

### 1.2 四幕护城河审计表

| 幕 | 护城河 | 强度 | 台词 |
| --- | --- | --- | --- |
| 幕一 · 贸易公司 | 无。执行速度 + 双语信任不构成壁垒 | ★☆☆☆☆ | 幕一只有两个任务:**不被踢开**(§2.2)+ **攒数据**(§2.1)。以为幕一有护城河的公司都死于自满 |
| 幕二 · 平台 | 双边网络(工厂竞标)+ 认证标准(Verified Factory)+ 数据飞轮 | ★★★☆☆ | 网络效应是「唯一不能被提示词生成的资产」 |
| 幕三 · 贸易银行 | 账面 + 数据风险定价 + 牌照/合规 | ★★★★★ | 真实坏账 <0.2% 而银行拒贷 41% ——**谁有履约数据,谁就能把拒掉的 41% 变成最好的资产** |
| 幕四 · 基础设施 | 标准(到岸表 = 行业格式)+ 生态(别人在你之上建) | ★★★★☆ | 到这里才是「龙头」的完全体 |

**护城河是相变,不是线性积累:** 幕一→幕二是网络效应开闸(买家越多→工厂竞标越密→报价越好),幕二→幕三是「数据变资本」(履约数据→风险定价→信贷账面→更多买家→更多数据)。每一幕的工程都必须在上一幕就开始建。

## 2. 六条护城河工程(核心)

每条工程四件套:**机制 / 第一天就要做的决策 / 健康度指标 / 反面教材**。

### 2.1 数据资产工程 —— 从第一单开始

- **机制:** 到岸表的 11 列不只是交付物,是数据采集器。每单沉淀:HTS 归类结果(含报关行复核)、验货报告、清关放行记录、实际交期、不良率、付款行为。这是银行拿不到、Cavela 没有、阿里不放在眼里的东西——而它正是把拒贷 41% 变成资产的唯一原料。
- **第一天决策:** (a) 数据模型 v0:每单必填字段表,「聊天记录里有」不算有;(b) 合同内置数据授权条款(脱敏、可授权第三方——为幕二的评分授权和幕三的风险定价留口子);(c) 履约记录「初期为空也诚实标注」,不造一条假数据。
- **健康度指标:** 累计结构化履约订单数 / 第三方调用评分次数 / 坏账率(目标 <1%)。
- **反面教材:** 数据散落在微信聊天和个人经验里 = 给竞争对手打工;卖了十年货但没有一列结构化数据的贸易公司,一夜之间被代理抹平。

### 2.2 责任锁定工程 —— 防被踢开(幕一唯一重要的事)

- **机制:** 让「绕过 Landed」的代价高于 6% 服务费:绕过 = 失去验货放款、账期、赔付担保、多国货源对冲、合规兜底。责任是买家离不开的东西,信息不是。
- **第一天决策:** (a) 买方寻源协议(赔付条款 + 数据授权 + 6% 透明费率,写进合同而非口头);(b) 工厂框架协议(保证金换优先响应与阶梯价);(c) 「跳单」定义与监测:买家拿到到岸表后直接联系工厂的订单数。
- **健康度指标:** 季度复购 GMV(>60% → 75%)/ 跳单率(<5%)/ 买家自评「换了 Landed 后不愿回去」比例。
- **反面教材:IndiaMART 的失血点** [R6-2]。它拥有 60% 的印度 B2B 发现份额,但用户「找到线索就离场」——运输和支付在平台外发生,平台被绕开(disintermediation),2025–26 连续两季付费供应商净减少。**发现层天生会漏,交易层才能锁。** IndiaMART 自己也想明白了:2026 年 6 月新设 IndiaMART Finance 冲向金融层。

### 2.3 标准占领工程 —— 到岸表 = 行业格式

- **机制:** 让「到岸表」成为买家比较任何报价的标准格式——像 Stripe 的发票、Plaid 的连接、IndiaMART 的 TrustSEAL。格式公开,数据留在我家。
- **第一天决策:** (a) **到岸表模板开放下载,竞争对手也能用**(反直觉,但格式占心智,填充数据才是资产);(b) 每张 PDF 底部带「由 Landed 生成 · 校验链接」(每份表是一张广告);(c) 公开「到岸成本」定义(FOB + 关税栈 + 运保杂 + 合规成本,逐项列示)——占领一个词。
- **健康度指标:** 到岸表被转发/引用次数 / 「到岸成本 landed cost」搜索词与品牌的共现率 / 外部报价单开始用 11 列格式的比例。
- **反面教材:** 把模板当机密锁起来 = 只有你自己在用,永远成不了标准。

### 2.4 密度工程 —— 先深后宽

- **机制:** B2B 网络效应是**局部**的:IndiaMART 的 60% 是「印度 B2B」这一个密度市场,不是全球。密度 = 询价响应速度 = 买家感知质量 = 工厂竞标密度(每张询价的合格报价数)。一条走廊做穿,第二条走廊几乎免费;五条走廊同时开 = 五个平庸的生意。
- **节奏(修订第五轮):** 第 0–15 月:中国→美国 × 宠物/厨房合规品类,做到「这个品类的卖家第一反应是 Landed」;第 2 走廊(越南/印度)在季度复购 >60% 后开;此后每 12 月 +1 走廊。**同一时间最多一条「做深中的走廊」+ 一条「试点中的走廊」。**
- **健康度指标:** 每张询价的合格报价数(≥5)/ 走廊内 SME 第一联想份额(半年一次 200 人样本调研)/ 复购 GMV。
- **反面教材:** 贪广度。五条走廊、十个品类、二十个人 = 每个格子里都是第三名。

### 2.5 资本工程 —— 债务即壁垒

- **机制:** 信贷设施本身就是护城河:没有账面的对手给不了买家 Net-60、给不了工厂早付折扣。坏账 <1% 的记录 → 更低的资金成本 → 更低的利率 → 更多买家 → 更多数据(飞轮)。资本不是「融资新闻」,是产品功能。
- **时序:** 第 12 月合作方资金试点(零自有风险)→ 第 27 月 $100–150M 债务设施 → 第 40 月 $1B + 仓储性融资 → 证券化。每一级都用上一级的坏账记录去换。
- **健康度指标:** 资金成本 vs 市场基准 / 坏账率(<1% 硬门槛)/ 账期渗透率(用账期的买家占比)/ 早付折扣采用率(工厂侧)。
- **警报:** Flexport×BlackRock($250M)[R6-1]、IndiaMART Finance[R6-2] 都在进场。但它们的基因数据是运价/搜索数据,**不是履约数据**——这场比赛的裁判是坏账率,而我们是唯一从第一天就记录「货到底到没到、合格不合格」的人。

### 2.6 判例库工程 —— 合规深度(组织知识变产品)

- **机制:** HTS 归类案例库、Prop 65 / CPSC / UFLPA 判例库、每个例外的处理记录。合规是 Flexport 海关业务毛利 +99% YoY 的原因 [R6-1];是小贸易商做不起、巨头不愿弯腰伺候长尾的层。判例越多 → 归类越准 → 一次通过率越高 → 买家越信。
- **第一天决策:** 每张到岸表的合规判定结构化归档;报关行复核结果回流入库(复核意见也是数据)。
- **健康度指标:** 归类案例数 / 海关放行一次通过率 / 合规类客诉率。

## 4. 龙头仪表盘:怎么知道自己在赢

**北极星:季度复购 GMV。** 一切护城河最终都汇进这一个数字。

| 工程 | 领先指标 | 健康线 |
| --- | --- | --- |
| 数据资产 | 累计结构化履约订单 / 坏账率 | 坏账 <1% |
| 责任锁定 | 复购 GMV / 跳单率 | >60% → 75% / <5% |
| 标准占领 | 到岸表引用量 / 词占领 | 「到岸成本」= 品牌词 |
| 密度 | 每询价合格报价数 / 第一联想份额 | ≥5 份 / 走廊内前二 |
| 资本 | 资金成本 vs 市场 / 账期渗透率 | 逐年下降 / >30% |
| 判例库 | 一次通过率 | 逐季上升 |

**止损 / 重定位信号(写死,防止叙事漂移):**
1. 第 40 月在 2 条走廊做不到 SME 采购第一联想前二 → 承认是利基贸易公司,按贸易公司估值,停止平台叙事(同第五轮断点纪律)。
2. 坏账率连续两季 >2% → 账期冻结,回查数据工程。
3. 跳单率 >10% → 责任产品失效,6% 的价值主张需要重建(先做用户访谈,不要先加功能)。
4. 阿里推出真·买方责任产品 → 触发防御预案(§3 第一行),12 个月内必须完成走廊密度 + 账期渗透的加速。

## 5. Ember / Praxis 的护城河工程(简表)

| 方向 | 护城河 | 工程 | 致命弱点 |
