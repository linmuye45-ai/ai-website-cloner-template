# 跨模型 · 跨轮次收敛追踪表

> 用法:每次让任何模型(GPT / Claude / Gemini / Grok / Qwen / Kimi …)执行三份任务书之一,把它给出的每个方案填一行。运行前务必把 `round-1` 第 0 节与 `round-2` 第 0 节的「2026-10 事实校准表」喂给模型,否则它会把 2024 年的热点当成 2026 年的空位。
> 评分沿用第三轮:天花板 30 / Demo 20 / 个人启动 20 / 壁垒 20 / 全球 10;淘汰线 90。
> 进入人工尽调的条件:**出现次数 ≥3(跨至少 2 个模型)且平均分 ≥88**,并能回答三个结构性问题。
