# OMNIVERSE：可玩内容平台方向与验证计划

## 愿景，不是财务承诺

OMNIVERSE 的方向是将交互内容创作、试玩和分发连接起来，长期探索一家价值 1,000 亿美元以上的公司是否有可能。**一年实现数亿元流动净资产、三年达到百角兽估值均为高度不确定的目标，不是已实现的业绩，也不能保证。** 估值不等于现金，更不等于创始人个人净资产。

## 当前交付

- 官方产品概念网站，以及可在浏览器中操作的原创流星躲避游戏。
- 创意工作台支持创建、删除和导出 JSON 草稿；数据保存在当前浏览器，清除浏览器数据可能丢失。
- 战略沙盘使用可调整的收入、成本及估值倍数展示简单算术，不是财务预测。
- 当前是静态前端原型：没有用户账户、服务器、真实 AI Agent、游戏生成、广告交易、支付或分发系统。开源工具尚未集成；使用前需核实许可证、版本和安全性。

## 产品路径

1. **验证创作者需求：** 与游戏工作室及买量团队访谈，确定一类可玩广告需求；制作能够编辑、预览并导出的单一格式。
2. **构建可付费试点：** 加入后端、身份验证、项目数据库、工作队列和资源存储；通过用户授权的模型 API 生成素材并人工审核。对目标平台做格式、性能和政策测试。
3. **验证经济性：** 收集真实销售、制作成本、买量成本、留存和付费数据，区分收入、毛利、税后利润、现金流与流动净资产。设置停损条件。
4. **扩大平台：** 仅在验证创作者需求和可靠分发之后，探索可玩内容信息流和广告服务。广告交易需要实际供需、反作弊、隐私保护、结算及合规，不能由模拟界面代替。

## 护城河假设

潜在优势包括高质量内容工具链、创作者与分发网络、经过许可的数据反馈和合规基础设施；这些都需要实际客户、数据和时间建立，而不是开源项目的简单拼装。

## 风险

产品需求、发行平台政策、版权及开源许可、用户隐私、广告归因、资金、税务、竞争和技术交付均可能影响结果。财务模型应基于真实数据、审慎假设和专业税务意见迭代。
