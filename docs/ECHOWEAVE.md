# ECHOWEAVE · 回声织网

永久试玩地址：**https://linmuye45-ai.github.io/ai-website-cloner-template/echo/**

一款吸血鬼幸存者结构的自动战斗游戏，但把「武器」换成了**玩家自己画出来的几何图形**。

## 一句话设计

> 你的走位轨迹就是武器。菜鸟绕圈保命，高手织网杀人。

## 核心机制

### 1. 轨迹即武器
- 玩家只控制移动，攻击全自动（幸存者类的基本契约）。
- 每 1.5 秒生成一个「回声」，它按接近原速重走你过去 5 秒走过的路径。
- 回声经过的网格单元被标记为**丝线**，持续 5.5 秒，敌人走进去就会被割伤。

这一点是反复调出来的关键：最初版本让回声直接碰撞敌人，结果**几乎打不到人**——因为敌人追的是你*现在*的位置，而回声走的是你*过去*的路径，两者在空间上错开了。无头测试里 87 秒只杀死 3 个敌人。改成「留下持续伤害的丝线」之后，敌人追你的过程本身就会不断穿过你留下的网，机制才成立。

### 2. 交叉才共振（创新点）
- 两种**不同元素**的丝线如果落在同一个格子，触发**共振爆炸**。
- 但触发有角度判定：两条线的夹角必须在 40°–140° 之间。
  - 平行线（并排走）→ 不炸
  - 原路折返（180°）→ 不炸
  - 真正成角度交叉 → 炸
- 结果是：**完美绕圈 = 0 次共振**。想要输出就必须主动制造路径自交，也就是画 8 字、画菱形、反复穿插。

这让「走位」第一次变成了有几何技巧上限的操作，而不是单纯的躲避。测试里绕圈机器人全程 0 次共振，8 字机器人每秒 0.32 次。

### 3. 六种元素组合，六种攻击形状

| 组合 | 效果 |
| --- | --- |
| 焰 + 霜 | 蒸汽爆：大范围高伤 + 击退 |
| 焰 + 雷 | 等离子链：连锁命中最远 6 个目标 |
| 焰 + 虚 | 奇点：先吸附再引爆 |
| 霜 + 雷 | 超导：范围内全体冻结 2.2 秒 |
| 霜 + 虚 | 晶牢：定身 + 持续割伤 |
| 雷 + 虚 | 湮灭：沿连接方向贯穿光束 |

开局只有焰元素，前 3 级必定提供元素核心，保证玩家能尽快接触到共振——否则这套核心机制会被锁在门外。

### 4. 局内成长
14 种强化覆盖四条轴：回声密度（频率/记忆深度/余韵/强度/半径）、共振（强度/范围）、生存（速度/磁吸/生命/再生）、元素解锁。升级时暂停并给三选一，数字键或点击选择。

### 5. Boss 曲线
60s / 140s / 240s / 330s 四波，最后一个是终局 Boss「终焉之织」，击杀即通关（织完了）。一局约 5.5 分钟。

## 技术要点

- **零素材**：没有任何图片或音频文件。所有图形用 Phaser `Graphics` 每帧程序化绘制（三角/四边/六边/十二边形），所有音效用 Web Audio 实时合成（振荡器包络 + 噪声 + 低频 pad）。
- **逻辑与渲染分离**：`src/echo/sim/` 是不依赖 Phaser/DOM 的纯 TypeScript 仿真层，可以无头编译跑完整局。
- **可无头回归测试**：`npm run test:echo` 会编译仿真层，用 4 种机器人策略（站桩 / 绕圈 / 织网 / 逃跑）各跑一整局，断言：
  - 站桩最终必死（移动是必需的）
  - 移动玩家确实能大量击杀
  - 回声确实在生成
  - 织网策略的共振频率显著高于绕圈
  - 无 NaN、敌人数量有界、血量不出界
- **性能**：自定义网格空间哈希做敌人分离与命中查询；丝线用网格标记而不是逐段碰撞；每帧渲染批次化。

## 为什么我认为它比原版更有机会

吸血鬼幸存者的乐趣核心是「构筑 + 屏幕清空」，但它的操作维度只有「往哪躲」。ECHOWEAVE 在同样的框架里加入了一个新的技巧维度：**你画的图形决定你的火力覆盖**。这让：

1. **可观赏性更强**——画面上是一张玩家自己织出来的发光几何网，短视频天然好看；
2. **技巧上限更高**——同样装备下，会不会织网直接决定输出；
3. **有可炫耀的量化指标**——结算页的「织网总长 / 共振次数」是可以截图分享的数字。

需要说明的是：机制创新能提高胜率，但「爆火和大卖」还取决于发行、社区运营、关卡内容量和持续更新，这些不是一次代码提交能保证的。
