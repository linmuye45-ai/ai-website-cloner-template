# 毛孩日报 PetDaily · 全球竞品与市场调研

> 日期:2026-10 · 范围:美国 / 中国 / 欧洲 / 日本 / 韩国 / 巴西 / 印度 · 风格:白话
> **产品定位(一句话):** 纯软件、零硬件的「宠物每日情绪小报」——30 秒生成一张能晒的日报 + 症状自查(就医时机建议)。新兴细分 = **宠物情绪 × 每日仪式 × 社交分享**。

---

## 一、为什么是这个细分(机会判断)

1. **宠物是全网第一流量密码,而且还在涨。** 全球宠物护理市场约 $3,000 亿;美国 $756 亿(全球 27.6%)、中国 ¥3,365 亿(2026E)、巴西 R$810 亿(全球第三)、日本 ¥8,800 亿(猫狗数量已多过婴儿)、印度 $24 亿且年增 15%+。驱动因素全球一致:晚生/不生孩子 →「毛孩子」升格为家人(中国 65.9% 视宠物为家人;90 后 + 00 后占养宠人群约 70%)。
2. **「情绪」这条细分刚被命名,还没有产品占住。** 中国 2026 年出了《宠物情绪行业白皮书》:情绪舒缓产品市场 2025 年约 ¥85 亿,2030 年将破 ¥111 亿——但里面全是喷雾、营养品,**没有一个「情绪与日常仪式」的软件产品**。内容侧:抖音一年新增 5,000 万宠物消费用户,内容平台是年轻人养宠的第一站。
3. **科学站在手机这一边。** 宠物「翻译」的独立研究:纯音频情绪识别准确率只有 **57.3%**;音频 + 视频 + 肢体语言可达 **89%**。也就是说:**手机摄像头方案比现在热卖的「音频翻译项圈」更有科学依据**——而且不用花 $100–700 买硬件。
4. **爆火机制是现成的:** 日报 = 每日分享燃料;周报/月报/年度大赏 = Spotify Wrapped 式刷屏;「像不像你家毛孩」测试 = 社交裂变。晒猫晒狗是全球通用语言。

## 三、竞争空位(为什么现在进场)

1. **硬件派互相打,没人做「纯软件日常」。** 项圈要买、要充电、要戴(宠物抗拒),独立研究还戳破了纯音频准确率(57%)。**手机 + 摄像头 + 每日记录 = 更可信、零成本、随时可用。**
2. **训练 App 是「课程」,不是「仪式」。** 打卡靠意志力;日报靠晒的动力——后者的留存引擎天生更强。
3. **问诊 App 病了才用;日报天天用。** 症状自查(就医时机)顺手嵌在日报里,平时的活跃度反哺关键时刻的信任。
4. **社交平台有内容没产品。** 晒宠物的内容在抖音/小红书/TikTok 上野蛮生长,但没有任何产品把「每天的它」沉淀成**可晒的资产**(卡片/周报/年报)。PetDaily 就是那台「晒资产制造机」。

## 四、爆火设计(viral loop)

1. **日报卡片天然带品牌**(报头 + 期数 + 「由毛孩日报生成」)——每张截图都是一次获客。
2. **周报 / 月度情绪曲线 / 年度可爱大赏**(Wrapped 式)——存量用户自传播的爆发点。
3. **「像不像你家毛孩」性格测试**——非养宠人群也能玩,裂变半径扩大十倍。
4. **品种榜 / 城市榜**(「今日最可爱柴犬」)——攀比心理 + 地域传播。
5. **接宠物殡葬/纪念的慢方向**(十年后的情绪价值终极形态)——暂不做,记在账上。

## 五、风险与诚实声明

| 风险 | 说明 | 对策 |
| --- | --- | --- |
| 「翻译」科学争议 | 独立研究纯音频仅 57% 准确 | **不承诺翻译**,定位「情绪小报 + 行为记录」;正式版走音频+视频+体态(研究口径 89%) |
| 门槛低被抄 | 规则引擎简单 | 靠数据(每只宠物的长期档案)+ 社区(榜单/测试)+ 品牌(报头心智)滚雪球;先发吃传播红利 |
| 医疗红线 | 症状建议涉及医疗 | 只谈「就医时机」,不谈诊断;免责明确;与问诊平台合作导流 |
| 变现担忧 | 宠物 App 付费难? | 反例:训练 App $8–10/月、Tractive/Fi 各近 $1 亿 ARR——宠物家长付费意愿已被验证;变现路径:免费日报 + Pro(多宠/年报/无水印/健康档案)$4.99/月 + 电商导流(粮/玩具) |

## 六、验证指标(第一周看什么)

1. **分享率:** 生成日报后截图/保存/分享的比例(>25% 健康线)。
2. **次日回访:** 明天还来出报的比例(>30% 健康线)。
3. **拉新:** 每张分享卡带来的新生成数(k 因子)。
4. **症状自查使用率:** 信任功能的渗透(>20%)。
