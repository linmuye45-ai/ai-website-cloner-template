# Hearthwarden: Ember Trail — 2.5D platformer supplement

**Art-bible addendum v1.1 · Extends [`ART_BIBLE.md`](./ART_BIBLE.md); it never overrides the locked palette, pixel scale or cluster rules.**

## 1. Why an original game and not a Mario clone

Research sources used for this supplement:

- Game Art Style — *Densely detailed pixel art* atlas entry
  <https://gameartstyle.loopyhop.com/styles/detailed-pixel/> — its own global
  direction requires "original designs and compositions rather than copying a
  particular game's characters, logos or artwork", and states the index is
  "not permission to extract or reuse game assets".
- Gameplay Atlas — mechanics field guide <https://gameplayatlas.loopyhop.com/>
  (280 mechanics, each reduced to a compact rule loop).

Genre conventions (running, jumping, stomping, collecting) are not owned by
anyone; specific expression (characters, names, logos, level layouts, iconic
objects) is. **Ember Trail is therefore an original cast and world in the
locked Hearthwarden style**, built on genre-universal mechanics plus mechanics
chosen from the Gameplay Atlas loops below. No third-party character, logo,
music or asset is reproduced.

## 2. Camera and 2.5D interpretation (locked)

| Parameter | Locked value |
| --- | --- |
| Internal framebuffer | 320 × 180 (same as art bible), integer-scaled only |
| Genre camera | side-scrolling, axis-aligned, no perspective projection |
| "2.5D" treatment | layered parallax depth + stepped lighting + contact shadows; no 3D models, no raster rotation |
| Parallax planes | sky (0.0) · far ridge (0.25) · mid hedge (0.55) · gameplay (1.0) · foreground silhouette (1.15) |
| Tile grid | 16 × 16, same tile size as the top-down bible |
| World / screen | camera follows the hero, integer-snapped, clamped to world bounds |
| Depth cue | airborne entities keep a shrinking stepped ground shadow; background planes use only the 2–3 darkest ramp steps; foreground is an INK/FOL1 silhouette |

## 4. Mechanics and their Gameplay Atlas source loops

| Mechanic in Ember Trail | Atlas mechanic (compact loop) | Reference entry |
| --- | --- | --- |
| Variable jump height — tap = hop, hold = full jump | Hold duration sets jump height: read landing → jump → choose release → adjust | `mechanic/movement-variable-jump/` (Celeste, Canabalt) |
| Run acceleration / friction with fine control | Switch speed to control reach and landing | `mechanic/movement-run-walk-control/` (Super Meat Boy, Spelunky 2) |
| Wall slide + wall jump | Walls as reusable anchors: read spacing → reach wall → push off → catch next | `mechanic/exploration-wall-jump/` (Super Meat Boy, Hollow Knight) |
| Ember Charge double jump, refilled on ground / at lantern nodes | Air movement and refill nodes: locate refill → spend charge → reach refill → plan next | `mechanic/exploration-air-action-refill/` (Celeste, Neon White) |
| Ember Dash with cooldown + brief invulnerability | Shared attack–defence stamina budget: every burst spends escape budget | `mechanic/combat-stamina-budget/` (Dark Souls III) |
| Stomp bounce with air combo multiplier | Bounce from a target into the next jump | `mechanic/movement-target-bounce/` (Hollow Knight, Spelunky 2) |
| Stomped Thornling → sprout → bloom → bonus shards | Planting and crop care: seed → growth interval → harvest (care automated to keep platformer pace) | `mechanic/farming-growth-care/` (Stardew Valley, Core Keeper) |
| Checkpoint lanterns + hearth goal | Exploration routes with safe anchors and a route terminus | Movement & traversal / Exploration & routes groups |
| Briarheart boss: telegraphed windup → timed weak-point window, projectile volleys that scale by phase, dash-as-defence | Attack–defence stamina budget + readable boss telegraphs; the dash both dodges and destroys seeds | `mechanic/combat-stamina-budget/` (Dark Souls III) |

### Boss contract — BRIARHEART (level 3 "Briarheart Thicket")

- 9 HP, three phases (3 stomps each). Loop per phase window: **idle (90f) →
  windup (55f, spikes raised, roar) → core exposed (100f) → hurt (26f)**.
- Damage is only possible by stomping the exposed core; side/top contact at
  any other time hurts the player. Each exposed window fires phase+1 ember
  seeds in aimed, gravity-arced spreads (2/3/4 seeds per volley).
- Dashing through a seed shatters it (dash i-frames), tying defence to the
  stamina-budget mechanic. On defeat the boss bursts into palette particles,
  drops a heart, and only then does the hearth accept the player.
- A dedicated ember-colour boss bar renders under the HUD scrim; the boss
  never uses colours outside the locked palette.

Quality-of-life feel rules (not sourced, standard platformer craft): coyote
time (6 frames), jump buffering (6 frames), fixed 60 Hz simulation, integer
camera, knockback i-frames on damage.

## 5. Readability and accessibility (measurable)

- Hero hitbox 16 × 38 inside the 32 × 48 sprite; enemy hitboxes ≤ 26 px wide.
- All gameplay text uses the authored 5×7 pixel font ported to
  `src/game/font-data.ts`; minimum cap height 7 native px (42 px at ×6).
- Hazard spikes occupy the lower 12 px of a tile and read as METAL triangles,
  never as ambient decoration.
- Interactive items bob on a fixed 2-frame pulse and carry at least one
  EMBER5/PARCH2 sparkle so they separate from foliage.
- Controls: keyboard (arrows/WASD, Space, Shift, P, Enter), standard
  gamepads (A/Cross jump, X/Square dash, Start pause/confirm, left stick or
  D-pad to move) plus on-screen touch targets ≥ 44 CSS px; full play without
  sound (visual cues only); mute toggle.
