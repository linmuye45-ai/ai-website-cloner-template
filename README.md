# The Dream Station

A mobile-first interactive-fiction prototype. Project code: NEXORA.

## Product boundary

- One original story world: the Dream Station.
- One character candidate: KURU, subject to IP/source-rights and trademark review.
- Three short, finite, authored chapters.
- Choices alter story state and endings; no open-ended AI chat.
- Mobile-first PWA with shareable story links.
- No account, payment, user text input, public UGC, global vote tally or server-side analytics in this prototype.
- Progress is stored locally in the user's browser.
- Private beta intended for adults 18+; the age declaration is self-reported and is not identity verification.

## Run

`npm install`
`npm run check`
`npm run dev`

## Current release status

This is a closed-test prototype, not a public commercial launch. Do not remove the noindex header until IP rights, safety, privacy, age assurance, market selection and launch compliance have been reviewed. Do not add global voting, accounts, payments or AI-generated user interactions until a dedicated backend and compliance review are approved.

## Product quality gates

- First meaningful action in under 10 seconds.
- Each chapter takes approximately 2–4 minutes.
- Three authored scenes per chapter.
- At least three distinct outcomes per chapter.
- No main-story choice is paywalled.
- Story progress is locally deletable.
- No false community counts or fabricated social proof.
- Test at 390 / 768 / 1440 CSS pixels.
